# Политика конфиденциальности LazyTv Droid

Репозиторий содержит публичную политику конфиденциальности Android-приложения
**LazyTv Droid** и служит постоянной ссылкой для карточки приложения в RuStore.

Опубликованная страница: https://mindwork64.github.io/lazytv-privacy/

## Состав

- `PRIVACY.md` — исходный текст политики (источник истины).
- `template.html` — HTML-обёртка страницы (стили, зависимости отсутствуют).
- `build.py` — генератор, собирает `index.html` из `PRIVACY.md`.
- `index.html` — опубликованная страница, собирается из `PRIVACY.md`.

## Как обновить политику

1. Изменить `PRIVACY.md` и обновить в нём дату последнего обновления.
2. Пересобрать страницу:

   ```bash
   sudo apt install python3-markdown   # если модуль ещё не установлен
   python3 build.py
   ```

3. Закоммитить `PRIVACY.md` и `index.html` и отправить в `main` — GitHub Pages
   пересоберёт сайт автоматически.

## Графика для RuStore

В каталоге `rustore/` лежат готовые изображения для карточки приложения:

- `icon-512.png` — иконка 512×512, RGBA, прозрачные углы.
- `cover-660x440.png` — обложка 660×440, RGB.

Обе картинки генерируются скриптом `make_assets.py` (нужен Pillow) и повторяют
иконку приложения: монограмма LT берётся из координат вектора
`app/src/main/res/mipmap/ic_launcher.xml` (viewport 108×108, штрих 8, round cap).

```bash
$ python3 make_assets.py
icon-512.png: (512, 512) RGBA
cover-660x440.png: (660, 440) RGB
```

Рядом создаётся `preview-sheet.png` — контрольный лист с иконкой на шахматке
(видно прозрачность углов) и обложкой. В карточку RuStore он не загружается.

### Требования RuStore

- Иконка: PNG, 512×512.
- Обложка: PNG или JPEG, 660×440.
- Скриншоты: от 3 штук, стороны от 320 px, соотношение не длиннее 2:1.

Шрифт — DejaVu Sans Bold из системного пакета `fonts-dejavu-core`.
