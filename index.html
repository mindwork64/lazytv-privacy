Политика конфиденциальности приложения «LazyTv Droid»

Дата последнего обновления: 21 сентября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») действует в отношении всей информации, которую приложение «LazyTv Droid» (далее — «Приложение») может получить о Пользователе во время использования им Приложения.

Использование Приложения означает безоговорочное согласие Пользователя с настоящей Политикой и указанными в ней условиями обработки информации. В случае несогласия с этими условиями Пользователь должен воздержаться от использования Приложения.

2. Какие данные обрабатывает Приложение

Приложение «LazyTv Droid» не собирает, не передаёт и не распространяет персональные данные Пользователя (такие как имя, номер телефона, адрес электронной почты, геолокация и т.д.).

Для своей работы Приложение использует следующие данные, которые хранятся исключительно локально на устройстве Пользователя и не передаются третьим лицам:

  • IP-адрес телевизора: используется для подключения к устройству в локальной сети.
  • Код сопряжения (pairing key): используется для установления доверенного соединения с телевизором.
  • Идентификатор сессии: используется для отправки команд управления.
  • Настройки приложения: такие как предпочтения по теме оформления и виброотклику.

3. Цели обработки данных

Указанные в разделе 2 данные обрабатываются исключительно в целях обеспечения работы основных функций Приложения:

  • Установление и поддержание соединения с телевизором.
  • Отправка команд управления (громкость, каналы, навигация и т.д.).
  • Сохранение пользовательских настроек для удобства использования.

4. Передача данных третьим лицам

Приложение не передаёт какие-либо данные третьим лицам. Вся информация, необходимая для работы, хранится локально на устройстве Пользователя.

Приложение не использует сторонние аналитические сервисы, системы краш-репортинга или рекламные SDK, которые могли бы собирать данные.

5. Разрешения, запрашиваемые Приложением

Для корректной работы Приложение запрашивает следующие разрешения:

  • Доступ к сети (INTERNET, ACCESS_NETWORK_STATE): необходимо для подключения к телевизору по локальной сети.
  • Доступ к вибрации (VIBRATE): используется для тактильного отклика при нажатии кнопок.

Все разрешения используются только для заявленных целей и не связаны со сбором персональных данных.

6. Безопасность данных

Поскольку все данные хранятся локально на устройстве Пользователя, их безопасность обеспечивается стандартными механизмами защиты операционной системы Android.

7. Изменения в Политике конфиденциальности

Разработчик имеет право вносить изменения в настоящую Политику. Новая редакция вступает в силу с момента её размещения. Пользователь обязуется самостоятельно отслеживать изменения.
